Payment Gateway untuk Website: Cara Kerja, Pilihan Integrasi, dan Cara Memasangnya

Jawaban singkat: Payment gateway untuk website adalah layanan yang menerima pembayaran pelanggan di situs Anda (QRIS, Virtual Account, e-wallet, kartu) dan mengabarkan statusnya ke situs secara otomatis. Anda bisa memasangnya lewat API, plugin, atau tautan pembayaran, tergantung platform dan kemampuan tim.

Ditulis oleh tim Wuzzpay (PT Semantic Digital Nusantara) · Diterbitkan 3 November 2026

Cara kerja payment gateway di website

  1. Pelanggan checkout. Pelanggan memilih metode pembayaran di halaman checkout situs Anda.
  2. Situs membuat transaksi. Situs (server Anda) meminta gateway membuat transaksi lewat API, lalu mendapat kode QRIS, nomor Virtual Account, atau tautan bayar.
  3. Pelanggan membayar. Pelanggan membayar lewat aplikasi bank atau e-wallet. Pembayaran diproses oleh gateway.
  4. Gateway memberi tahu situs. Gateway mengirim notifikasi (webhook atau callback) ke server Anda bahwa pembayaran berhasil.
  5. Pesanan diperbarui otomatis. Server Anda memverifikasi notifikasi itu lalu mengubah status pesanan menjadi lunas.

Detail alur, webhook, dan pengujian ada di panduan integrasi pembayaran ke aplikasi SaaS.

Metode pembayaran yang sebaiknya tersedia

Pelanggan berbeda-beda cara bayarnya. Untuk toko online di Indonesia, kombinasi yang umum adalah QRIS, Virtual Account bank, dan e-wallet, dengan gerai retail atau kartu sebagai tambahan sesuai pelanggan Anda. Perbedaan tiap metode dijelaskan di panduan menerima pembayaran QRIS dan VA.

Kriteria memilih payment gateway untuk website

  • Cara integrasi. Sesuai dengan platform dan kemampuan tim Anda, dengan dokumentasi yang jelas.
  • Metode yang didukung. Cocok dengan kebiasaan bayar pelanggan Anda.
  • Total biaya. Biaya aktivasi, biaya per transaksi, PPN, dan biaya lain. Lihat cara menghitung MDR.
  • Legalitas. Dana diproses oleh pihak berlisensi Bank Indonesia.
  • Settlement. Kapan dan ke mana dana dicairkan.
  • Keandalan. Bagaimana penyedia menangani gangguan. Lihat kriteria memilih gateway dengan failover.
  • Dukungan. Kepada siapa Anda bertanya saat ada transaksi bermasalah.

Keamanan dasar yang perlu diterapkan

  • Pasang HTTPS di seluruh situs, terutama halaman checkout.
  • Simpan kunci API di server, bukan di kode yang bisa dilihat pengunjung.
  • Verifikasi setiap notifikasi webhook (misalnya tanda tangan atau pengecekan status ke gateway) sebelum menandai pesanan lunas.
  • Jangan menganggap pelanggan yang kembali ke halaman sukses sudah pasti membayar; andalkan notifikasi dari gateway.
  • Jangan menyimpan data kartu sendiri; biarkan gateway yang menanganinya.

Langkah memasang payment gateway di website

  1. Daftar dan lewati verifikasi. Lihat cara daftar payment gateway untuk dokumen dan alurnya.
  2. Pilih cara integrasi. API, plugin, atau tautan pembayaran, sesuai platform Anda.
  3. Pasang di lingkungan uji. Gunakan mode uji (sandbox) bila tersedia untuk mencoba transaksi tanpa uang sungguhan.
  4. Tangani webhook. Buat endpoint yang menerima notifikasi, memverifikasinya, dan memperbarui pesanan dengan aman.
  5. Uji setiap metode. Coba pembayaran berhasil, gagal, dan kedaluwarsa untuk tiap metode.
  6. Buka untuk pelanggan dan pantau. Cocokkan laporan transaksi dengan mutasi rekening secara rutin.

Pertanyaan yang sering diajukan

Payment gateway apa yang cocok untuk website?

+
Yang mendukung metode bayar pelanggan Anda, punya biaya yang jelas, diproses pihak berlisensi Bank Indonesia, dan cara integrasinya sesuai dengan platform serta kemampuan tim Anda.

Apakah payment gateway bisa dipasang di WordPress atau WooCommerce?

+
Bisa, lewat plugin bila penyedia menyediakannya, atau lewat integrasi API oleh developer. Tanyakan ketersediaan plugin untuk platform Anda ke penyedia sebelum mendaftar.

Apakah website perlu HTTPS untuk memakai payment gateway?

+
Ya. Pasang HTTPS di seluruh situs, terutama halaman checkout, agar data pelanggan terlindungi dan sesuai kebutuhan banyak penyedia.

Bagaimana website tahu pembayaran pelanggan sudah berhasil?

+
Gateway mengirim notifikasi (webhook atau callback) ke server Anda. Server memverifikasinya lalu memperbarui status pesanan secara otomatis.

Berapa biaya payment gateway untuk website?

+
Umumnya terdiri dari biaya aktivasi atau integrasi dan biaya per transaksi yang berbeda tiap metode, belum termasuk PPN. Contoh tarif Wuzzpay ada di halaman Biaya Transaksi, dan tarif dapat berubah.

Apakah Wuzzpay menyediakan integrasi untuk website?

+
Wuzzpay menyediakan integrasi lewat satu API dan dashboard merchant, dengan dokumentasi di docs.wuzzpay.com. Untuk platform tertentu seperti WordPress atau WooCommerce, tanyakan ketersediaannya ke tim lewat WhatsApp.
